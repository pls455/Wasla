# وصلة | Wasla

تطبيق Flutter لنقل الملفات مباشرة بين الأجهزة عبر الشبكة المحلية، بدون رفع الملفات إلى خادم مركزي.

## MVP
- اكتشاف الأجهزة القريبة عبر UDP broadcast.
- اتصال مباشر TCP بين الجهازين.
- قبول أو رفض طلب الاستقبال قبل النقل.
- إرسال عدة ملفات مع تدفق مباشر، بدون تحميل الملف كاملاً إلى الذاكرة.
- SHA-256 للتحقق من سلامة الملفات.
- أساس لاستئناف النقل باستخدام ملفات `.part`.
- سجل محلي واسم جهاز قابل للتعديل.
- واجهة عربية RTL مع Material 3 ووضع فاتح/داكن.

## Build
```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

البناء الآلي موجود في GitHub Actions، ويولد مشروع Android القياسي ثم يبني APK Release ويرفعه كـ artifact.
